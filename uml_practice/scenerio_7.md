An airline wants a complete booking and flight system. The airline owns many planes. A plane has a code, a model, a number of seats and an age. Each plane has seats in two classes, economy and business. A seat has a number, a class and a status.

The airline runs flights. A flight has a flight number, a departure airport, an arrival airport, a departure time and an arrival time. One flight uses one plane. The same plane can be used for many flights on different days. An airport has a name, a code and a city.

Every flight has a crew. The crew has pilots and flight attendants. A pilot has a license number and flying hours. A flight needs two pilots and at least four attendants. A crew member cannot work two flights at the same time. The system must check this rule.

A passenger can search for flights by date and city. The passenger picks a flight and a seat and makes a booking. A booking can have many tickets, one for each passenger. A ticket has a price, a seat and a passenger name. Business class tickets cost more and include free meals and extra bags.

Passengers must give a passport number. The system checks that the passport is not expired. Passengers can also add extra bags. Each extra bag has a weight and a fee. If a bag is too heavy, the passenger pays more.

On the travel day, the passenger checks in and gets a boarding pass. The boarding pass has a gate and a boarding time. If the flight is delayed, the system sends a message to all passengers on that flight.

A passenger can cancel a booking. The refund depends on the time left. A full refund is possible up to 48 hours before the flight. After that, the refund is only half.

Frequent flyers collect miles. They can use miles to pay for tickets.
