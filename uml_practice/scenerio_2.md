A town library needs a simple system. The library has many books. Each book has a title, an author, an ISBN number and a status. The status can be “available” or “borrowed”.

People can join the library as members. A member has a name, an ID number, an address and a join date. A member can borrow up to five books at one time.

When a member borrows a book, the system saves a loan. A loan has a borrow date and a due date. When the member brings the book back, the system saves the return date. If the member returns the book late, the member must pay a fine. The fine is 10 cents for each late day.

The library has librarians. A librarian has a name and a staff number. A librarian can add a new book, remove an old book and check a loan. Only a librarian can do these jobs. A member cannot.

The library also has different book types. A normal book can be borrowed for 14 days. A magazine can be borrowed for only 3 days. A reference book cannot be borrowed at all. Students can read it only inside the library.
